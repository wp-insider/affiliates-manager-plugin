# Affiliates Manager

Official GitHub repository of the **Affiliates Manager** WordPress plugin.

Affiliates Manager lets you run an affiliate program on your WordPress site. It handles affiliate recruitment, registration, login and management, tracks the referrals your affiliates send, and awards commissions. It works with popular e-commerce and membership plugins such as WooCommerce, Easy Digital Downloads, MemberPress, Paid Memberships Pro, Simple Membership, Stripe Payments and GiveWP.

## Installation

Install the plugin from **Plugins > Add New** in your WordPress admin by searching for "Affiliates Manager". You can also download it from [WordPress.org](https://wordpress.org/plugins/affiliates-manager/) and upload the zip file. Then follow the [documentation](https://wpaffiliatemanager.com/documentation/) to set up your affiliate program.

This repository holds the development version. The plugin code is in the [`wpaffiliatemanager`](wpaffiliatemanager) folder.

## Contributing

Bug reports and pull requests are welcome. When submitting a pull request:

- Keep the code compatible with PHP 7.4. Don't use PHP 8.0+ only syntax such as `match`, enums, `readonly`, constructor property promotion, the nullsafe operator `?->`, union types or named arguments.
- Follow the WordPress coding practices already used in the plugin: sanitize input, escape output, and use nonces and capability checks for admin actions.
- Describe the problem and how you tested the fix.

If you need an extra hook or filter for your integration, open an issue and let us know.
